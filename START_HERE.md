# Cursor prompts and assets — start here

This is the requested design/build brief and asset kit. Cursor will create the Next.js website code. No prebuilt website source, package.json, executable scripts, or deployment workflow files are included.

## Use this kit

1. Extract the ZIP and open the complete apefest-cursor-prompts-assets folder in Cursor.
2. Open Cursor Agent and paste the short instruction below, or paste the full contents of brief/CURSOR_BUILD_PROMPT.md.
3. Cursor should inspect the brief and images, then build the Next.js application at the project root while preserving brief/.
4. Use brief/CURSOR_UPDATE_PROMPTS.md for later image, text, token-information, and staging updates.

Paste into Cursor:

    Read brief/CURSOR_BUILD_PROMPT.md and every document it references.
    Inspect brief/assets and brief/reference-data. Build the Next.js website
    from this specification in the current project root. Use the supplied
    artwork and approved layout. Keep unknown token information pending.
    Preserve brief/ as the design and update reference. Implement the documented
    staging automation and report any account setup still required.

## What is included

- A complete initial build prompt and five reusable update/review prompts.
- The approved design specification, research/context notes, and acceptance checklist.
- An exact mapping for future information and image updates.
- Ten original illustrations: one hero, six souvenirs, and three ape expressions.
- Optimized website image variants and a derived favicon.
- An asset guide with image dimensions, intended uses, and stable IDs.
- Reference JSON for site identity, assets, page copy, historical chapters, and memes.
- Requirements for Cursor to create automatic Git commits, staging pushes, and Preview deployments.
